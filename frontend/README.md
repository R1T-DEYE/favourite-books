# Favourite Books — Frontend

React + Vite client for the **Favourite Books** coursework bookstore.

It provides customer and staff screens for browsing books, managing the cart, completing a **simulated** checkout, and viewing catalogue and sales information.

For the architecture, test account details, local setup, and important security limitations, see the [repository README](../README.md).

```bash
npm ci
npm run dev
```

The frontend expects the FastAPI demo backend at `http://localhost:8000`.

**Use fictional details only.** This application does not process real payments.
